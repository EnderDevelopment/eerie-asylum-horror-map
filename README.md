# Eerie Asylum

Eerie Asylum is a Roblox horror map designed to create a terrifying atmosphere and challenge players. This project includes scripts for ambient sounds, fog effects, monster spawning, player effects, and trigger events to enhance the horror experience.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the scripts in the appropriate locations within your game.

## Use

1. **AmbientSounds.lua**: This script handles ambient sounds to create a sense of unease. Place it in the `ServerScriptService` or any other appropriate service.
2. **FogEffect.lua**: This script manages the fog effect to limit visibility and add to the horror. Place it in the `ServerScriptService`.
3. **MonsterSpawner.lua**: This script spawns monsters at random intervals to scare the players. Place it in the `ServerScriptService`. Ensure you have a monster model in `ReplicatedStorage` named "Monster".
4. **PlayerEffects.lua**: This script applies visual and audio effects to the players to enhance the horror experience. Place it in the `ServerScriptService`.
5. **TriggerEvents.lua**: This script sets up trigger events that occur when players enter certain areas. Place it in the `ServerScriptService`. Make sure to replace the `triggerParts` with your actual trigger parts in the workspace.
